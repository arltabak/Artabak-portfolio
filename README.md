# Ariel Tabak — Portfolio

Personal engineering portfolio, served with GitHub Pages.

Plain HTML + CSS, no build step:

- `index.html` — home page (intro, project grid, about, contact)
- `projects/*.html` — one page per project
- `assets/style.css` — all styling (colours and fonts are set at the top)
- `images/projects/` — project photos (placeholders are `.svg`; replace with `.jpg`/`.png` and update the `src`)

Anything marked **TODO** on the site still needs real content.
